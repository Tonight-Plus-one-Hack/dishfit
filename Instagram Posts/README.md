## About the package / Zum Paket

The videos use actual screens from the local repository beta; the app interface is German in both versions. Nutrition values are AI estimates, and AI image labels remain visible. The instrumental music was created for these videos without third-party samples. No live website or launch date is claimed. Upload the desired MP4s manually to Instagram; nothing is published automatically.

Die Videos zeigen echte Aufnahmen der lokalen Beta mit deutscher Oberfläche. Nährwerte sind KI-Schätzungen; Hinweise auf KI-Bilder bleiben sichtbar. Die Instrumentalmusik wurde für diese Videos ohne fremde Samples erstellt. Es wird keine Live-Website und kein Startdatum genannt. Die gewünschten MP4s können manuell bei Instagram hochgeladen werden; es wird nichts automatisch veröffentlicht.

This GitHub upload edition is flat: `EN-` identifies English assets and `DE-` German assets. The original local `Instagram Posts` package uses separate `English/` and `Deutsch/` folders. The video files are identical in both layouts.

Diese GitHub-Fassung liegt in einem einzigen Ordner: `EN-` kennzeichnet englische, `DE-` deutsche Dateien. Das ursprüngliche lokale Paket `Instagram Posts` verwendet die getrennten Ordner `English/` und `Deutsch/`. Die Videodateien sind in beiden Fassungen identisch.

Both export reports show 12/12 successful checks: [English validation](EN-validation.json) · [Deutsche Exportprüfung](DE-validation.json). [manifest.json](manifest.json) lists file sizes, SHA-256 hashes and reference checks. Tools, source-site files, raw screenshots and credentials are excluded.
